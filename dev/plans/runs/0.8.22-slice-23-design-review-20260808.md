## Review round 1 findings

1. **P2 — validity time was not frozen.** `ReadView.valid_as_of=None` resolves
   to the current time per request, so it cannot support an across-call prefix
   assertion when its effective value changes.
2. **P2 — stale direct-text documentation was under-scoped.** The intended
   updates had to correct false node-only/no-fusion descriptions as well as add
   the prefix contract.
3. **P2 — the 0.8.23 follow-up note omitted the mandated question.** It needed
   to state the hybrid/vector candidate-fanout versus caller-limit decision.

## FIX-1 and re-review

FIX-1 requires the same immutable snapshot and effective validity time,
requires explicit fixed `valid_as_of` / `validAsOf` in `ReadView` RED fixtures,
and documents the `None`/current-time qualification. It requires all affected
contracts to say that direct text-only omits embedding/vector/CE/graph stages
while matching node- and edge-body candidates participate in deterministic body
deduplication and ranking. `dev/notes/0.8.23-architecture-tradeoffs.md` now
requires the broader hybrid-prefix contract/fixed-fanout/non-guarantee ruling
without expanding Slice 23 or blocking 0.8.22.

The independent FIX-1 re-review found no P1/P2.
