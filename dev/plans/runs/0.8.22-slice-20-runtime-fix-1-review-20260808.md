## Verdict: BLOCK

Two new P2 findings require `FIX-2`.

### 1. [P2] Shell literals can still spoof the invocation

The parser scans every non-comment line in a selected `run` body as executable.
It does not recognize Bash heredocs or PowerShell here-strings. A canonical
invocation inside either non-executing literal plus a wrong actual invocation
still passes.

`FIX-2` must parse or fail closed on those literal regions and add both negative
controls.

### 2. [P2] Continuation normalization accepts invalid whitespace-suffixed forms

The parser right-trims before checking a trailing Bash backslash or PowerShell
backtick. It therefore accepts forms that the respective shell does not treat
as continuations.

`FIX-2` must detect a continuation before trimming trailing whitespace and add
negative controls for both invalid forms.

## What passed on inspection

The wrong path, wrong label, comment, `Write-Output`, and valid PowerShell
continuation controls work. Scope remains limited to the local guard; no
production workflow/helper, GitHub, publish, or release-state file changed.
