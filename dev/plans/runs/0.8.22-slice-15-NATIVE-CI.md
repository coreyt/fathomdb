# 0.8.22 Slice 15 — NATIVE-CI

## Local result

The candidate adds a five-target `native-artifact-runtime-validation` CI job.
For every release-ready runner it builds the local Python wheel and matched
N-API platform package, then installs and exercises only those local
artifacts. The pre-publish check is deliberately distinct from Slice 20's
registry smoke.

Local verification passed on the candidate through `24c86d83`:

- actionlint on `.github/workflows/ci.yml`;
- full `scripts/agent-verify.sh`;
- the native-artifact structural guard, including negative controls for target,
  feature, native-build, TypeScript-build, registry-substitution, and Windows
  Python-exit propagation drift;
- the release-contract and five-target platform-scope guards, ShellCheck, and
  `git diff --check`;
- a supplementary Linux x64 runtime execution: a locally built Python abi3
  wheel and matched local N-API package were installed without a registry,
  then each SDK opened, wrote, searched, closed, and exited successfully.

Independent review required and verified three remediations before this record:
the structural test now asserts the substantive build wiring, the PowerShell
helper propagates failed Python wheel install/smoke exits, and the PowerShell
guard test matches the exit mechanism rather than diagnostic wording.
