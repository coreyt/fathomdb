# Slice 23 — FTS-LIMIT-PREFIX-STABILITY

> **Execution status:** planned corrective slice. Before implementation, run a
> fresh pickup review of this plan and its design, re-verify every code anchor,
> and move the slice from proposed to ready only if no P1/P2 issue remains.
> Slice 20 publication remains held until this slice is landed and verified.

## Mandate

Repair the P2 defect in which direct FTS-only search can change its top-K
contents when the caller requests a larger result limit. Deliver a bounded,
limit-independent candidate collection for `search_text_only`, prove it with
RED→GREEN real-database tests in Rust, Python, and TypeScript, and document the
result-prefix contract.

This is a behavioral repair for existing API spellings. It must not add an SDK
knob, alter the accepted `1..=100` returned-result contract, make a schema
change, modify graph expansion, cap edge FTS, or redesign hybrid/vector search.

## Required TDD sequence

1. **Design/pickup gate.** Re-review this plan and the design before any source
   edit. Confirm the direct-text-only discriminator is necessary to avoid
   changing ordinary hybrid fallback semantics.
2. **RED engine.** Commit an adversarial real-database regression fixture: at
   least 50 matching nodes and a matching edge whose body duplicates a node
   outside the first ten node candidates. Assert ordered IDs and scores for
   `small=10`, `large=50`, and the `ReadView` form with an explicit fixed
   `valid_as_of` / `validAsOf`. Run and record the failing baseline test.
3. **RED bindings.** Commit equivalent Python and TypeScript real-engine tests
   through the existing wrappers. Run them against the baseline implementation
   and record their failures.
4. **GREEN.** Add a private reader-request discriminator/bound that only the
   explicit direct text-only entry point supplies. Use fixed node candidate
   bound 100, preserve current edge collection and post-fusion truncation, and
   correct the stale implementation commentary. Make every RED test green.
5. **Refactor and docs.** Keep the private request plumbing minimal, update the
   required contracts/docs, and record the bounded-cost evidence. No test may
   be weakened to obtain green.
