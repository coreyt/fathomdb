# Slice 12 — DOC-BASELINE

## Mandate

Produce a reproducible, Phase-1-only classification of the current FathomDB
documentation surface and its debt. This is the existing `repo-prune` model:
classify and record; do not execute a cleanup.

## Required reading

- `scripts/repo-prune/README.md`
- `scripts/repo-prune/prompts/prune-docs.md`
- `scripts/repo-prune/runs/doc-prune-CLEANUP-MAP.md`
- `dev/design/steward-cold-start-budget.md` §§ 1a and 5
- `dev/DOC-INDEX.md`
- `dev/plans/plan-0.8.22.md`

## Deliverables

1. Run `scripts/repo-prune/bin/context-clarity.sh 0.8.22-s12-baseline` and
   commit its JSON and Markdown evidence.
2. Create one bounded classification artifact under `scripts/repo-prune/runs/`
   with the candidate revision, command, and timestamp. It must distinguish:
   current authority; historical record that stays in place; and unresolved
   document debt. For each unresolved item, name the existing owning index or
   release home; do not create a parallel, permanent index.
3. Reconcile the known `repo-prune` evidence discrepancy (the README's
   660-file count versus the baseline/DELTA 670-file count) as a classified
   document-debt finding, not a silent correction.
4. State explicitly that Phase 2 is not authorized by this slice. No document
   may be deleted, moved, archived, rewritten, or link-repaired.

## Boundaries

- Do not change source, bindings, workflows, public contracts, release state,
  or the release plan.
- Do not alter `dev/DOC-INDEX.md`; report a proposed index change as debt for
  its future owner.
- Do not add a second current-authority index. The classification artifact is a
  one-time `repo-prune` run record, not a replacement index.
- Do not run network-dependent link checking.

## Verification

Run the clarity command, `scripts/agent-lint-md.sh`, and `git diff --check`.
Record their actual exit status in the closure artifact. Commit only the
bounded run artifact and its measurement outputs.
