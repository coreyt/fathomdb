# THE CLASS: `producer | head` / `producer | grep -q` under `set -o pipefail`.

# producer takes SIGPIPE and pipefail poisons the rc. Inside an `if` condition
# `set -e` is suspended, so the guard does not abort — it fails OPEN, and does
# so precisely when it had something to report. Four hand-fixes, no gate. This
# leg is the gate.

# clean fails the gate until its line is deleted), and a listed path that is
# not a tracked *.sh also fails.
